# MiQroForge Desktop V1 产品形态及技术边界说明

> 版本：3.0 ｜ 适用版本：MiQroForge Desktop 0.25.0（Alpha）｜ 本文档只描述产品形态与当前已实现的功能，不含技术实现细节

---

## 1. 产品形态

**MiQroForge Desktop 是一个本地优先的个人 AI 助手桌面应用**：把 AI 代理引擎与桌面界面结合，用户可以用自然语言完成对话问答、文件处理、办公文档生成、定时任务等工作；所有数据保存在本机，不上传云端。

- **形态**：桌面应用，提供 Windows / macOS 安装包（含便携版、安装器、MSI、磁盘镜像等），开箱即用，无需额外安装运行环境；
- **首次使用流程**：隐私协议确认 → 设置向导（环境检查 → WSL2 配置（仅 Windows）→ 模型配置 → 工作目录），完成后可随时从设置页重新进入向导；
- **主界面布局**：左侧会话任务板 + 中央内容区 + 顶部工具栏 + 底部状态栏。

## 2. 功能总览

### 2.1 会话任务板（侧边栏）

- 每个对话都是一个「任务」，可按状态分组查看：**全部 / 进行中 / 待审阅 / 已完成**，各状态带数量角标；
- 新建会话、列表无限向下滚动加载；
- 右键任务菜单：标记状态（进行中/待处理/待审阅/已完成）、**在文件管理器中打开**（定位该会话的工作区）、重命名、重置状态、归档、删除；
- 批量操作：删除全部任务、归档全部任务；
- 每条任务显示所属工作区路径与最近更新时间（如「x 天前更新」）；
- 侧边栏宽度可自由拖拽调整。

### 2.2 聊天

- 多轮对话、流式输出、打字机逐字动画（切换会话后自动补齐）；
- 随时停止当前回答；
- **中断恢复**：进程退出或手动中断后，可从断点一键继续；存在多条历史对话时可选择从哪一条恢复；
- **附件**：图片（拖拽/粘贴）、办公文档（Word/PPT/Excel/PDF 等）、文本文件；
- **执行过程实时可见**：工具名称与参数、命令输出内联展示；子代理（分工执行的助手）结果单独展示；
- **文件修改展示**：AI 对文件的改动以差异对比形式呈现，可逐条回滚或确认接受；
- **成果预览**：生成的 Word、表格、网页文件可在聊天内直接预览；
- **排版与阅读**：Markdown 排版（表格、任务列表等）、180+ 语言代码高亮、AI 推理过程折叠展示、推理模式开关；
- **确认卡**：任务执行过程中，AI 可以反过来向你提问或请求确认（文本或选项）；
- 会话内操作：重命名、切换工作区、消息按时间分组。

### 2.3 工作区文件管理

- 文件树浏览（含右键菜单）；
- 文件操作：**新建文件/文件夹、重命名、删除**（删除有确认提示）；
- 内置文本编辑器：**未保存更改提示**、Ctrl+S 保存、切换文件前确认；
- 预览模式：Markdown 与 HTML 文件即时渲染预览；
- 文件版本操作：**差异对比、回滚、接受变更**；
- 打开方式：用系统程序打开、**在文件管理器中定位**、HTML 在浏览器中打开、下载保存。

### 2.4 会话管理

- 双栏浏览：会话列表（可刷新、显示运行中智能体状态）+ 消息详情（用户/助手/工具消息分样式展示）；
- 会话操作：打开、复制会话标识、删除；
- **旧版会话认领**：旧版本创建的会话可一键迁移到当前版本；
- 无权限访问的会话有明确提示；
- 归档管理：已归档会话可恢复或彻底删除。

### 2.5 计划跟踪

- 复杂任务自动生成执行计划，步骤状态实时更新：待处理 / 进行中 / 已完成 / 已跳过。

### 2.6 审批与权限

- **审批中心**：待审批操作队列（命令/时间/会话一目了然），在聊天内弹窗即时同意或拒绝；可查审批历史；
- **审批绕过模式**：五个独立开关——全部绕过、命令审批、文件写入审批、工具确认、网络审批；开启绕过时顶部常驻警示横幅；
- **白名单**：常用命令可永久放行，也可随时清除；
- **权限策略**：文件读取/写入各自独立设置（始终审批 / 免审批 / 白名单模式 / 禁止）；命令执行三档（仅危险命令 / 允许所有 / 全部阻止）；网络策略。

### 2.7 智能体监控

- 查看正在运行的智能体：类型、任务、状态（空闲/思考中/执行中/已完成/错误/已中止，彩色状态点实时变化），新智能体启动自动刷新。

### 2.8 扩展能力：MCP / 技能 / 插件

- **MCP**：接入外部工具服务器（命令行或远程地址），可设工具超时，支持按需激活工具；
- **技能**：浏览技能列表与详情、新建技能（名称 + 描述）、删除技能；
- **插件**：查看已安装插件（名称/版本/状态），一键启用/禁用/卸载。

### 2.9 记忆与经验

- **记忆**：管理记忆文件（用户画像、项目知识等）——选择查看、编辑、新建，未保存有标记；经验教训记录（正确做法/错误做法对照）；
- **经验**：浏览 AI 积累的经验规则（正确行为/错误行为）与历史记录。

### 2.10 定时任务

- 查看定时任务（调度、下次运行时间、最近状态、创建时间），新建与删除。

### 2.11 设置中心（22 个标签页）

按功能域分组，修改后**自动生效，无需重启**：

| 标签 | 功能 |
|---|---|

| 渠道 | 接入飞书等消息渠道、消息合并窗口时间 |
| 审批 | 同 2.6 审批中心 |
| 工作区 | 同 2.3 工作区文件管理 |
| 网络工具 | 网络搜索、网页抓取、论文研究工具的配置 |
| 外观 | 主题、界面字号、代码字体大小、表情样式、对比度、减少动态效果（跟随系统）、侧边栏半透明毛玻璃 |
| 智能体 | 同 2.7 智能体监控 |
| 技能 | 同 2.8 技能 |
| MCP | 同 2.8 MCP |
| 记忆 | 同 2.9 记忆 |
| 经验 | 同 2.9 经验 |
| 权限 | 同 2.6 权限策略 |
| 插件 | 同 2.8 插件 |
| Qraft | Qraft 平台账号登录（手机号/扫码）、令牌状态、环境选择、计划自动刷新 |
| 定时任务 | 同 2.10 定时任务 |
| WSL | 同 2.12 WSL 状态 |
| 日志 | 按来源（主程序/界面/引擎/工具/沙盒/消息）与级别（信息/警告/错误）过滤查看运行日志 |

| 法律文件 | 用户协议、隐私政策、隐私政策摘要、个人信息收集清单、个人信息对外提供清单全文查阅 |
| 文档 | 内置帮助文档 |
| 反馈 | 提交反馈（自动附带运行日志发送给开发团队）、查看反馈记录 |

### 2.12 WSL 状态（Windows）

- 选择发行版查看实时资源占用（CPU、内存、磁盘）与详细信息，支持手动刷新。

## 3. 暂不提供的范围

- 网页版与手机版客户端；
- 多账号体系与云端数据同步（数据保存在本机）；
- 容器化部署方式；
- 交互式终端窗口（在应用内直接操作的命令行界面）。
