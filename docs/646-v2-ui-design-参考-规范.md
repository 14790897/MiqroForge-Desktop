# MiQi UI 设计参考规范（2026-08-18，WorkBuddy 体系学习沉淀）

> 来源：Kimi k2.6 多模态分析用户提供的 5 张参考截图（WorkBuddy ×3 + 趋势地图 ×1 + 提问选择卡 ×1）。
> 用途：#646-v2 卡片/消息/任务列表 UI 改造的落地基准。

---

## 一、AI 消息形态（学 WorkBuddy）

| 项 | 参考做法 | MiQi 改法 |
|---|---|---|
| 对话框 | **无气泡，正文平铺**（不是对话框） | AI 消息去气泡——正文直接平铺（用户已提议，Kimi 评估可行） |
| 头像 | 圆形小头像（16px）+ 名字"风向标"在**页眉行** | 保留 16px 小头像 + 名字 + 状态徽章——放消息顶部页眉行（用户："头像放上面"） |
| 状态标签 | "深度思考"灰色小字 + 消耗（已消耗 6.02） | AI 页眉行加：深度思考标签 + 消耗显示（可选） |
| 用户消息 | 右对齐灰色气泡 | 保持（层级区分靠用户气泡 vs AI 平铺） |

## 二、卡片体系（学 WorkBuddy + 趋势地图）

| 项 | 参考做法 | MiQi 改法 |
|---|---|---|
| 位置 | **嵌入对话流**（不浮层——保持阅读动线） | 保持对话流内 ✓（已验证正确） |
| 背景 | 卡片浅灰背景嵌入（非纯白） | PlanCard/Timeline 卡本体可浅灰化（步骤区已浅灰） |
| 圆角 | 卡片 16-20px / 按钮 8-12px | ✅ 已改 16px |
| 主按钮 | 深灰/近黑（#1f1f1f）圆形或圆角 | ✅ 已改近黑（矩形圆角 6-8px） |
| 步骤指示 | "1/4" 进度指示 + 关闭按钮 | PlanCard 可加"第 X 步"指示 |
| 选项即按钮 | 列表项即选择（悬停浅灰 + 箭头） | ActionCard 确认按钮已深色化 |
| 确认后 | **确认即关闭，不留痕** | ✅ 已改（resolved 不占对话流） |
| 生成中状态 | "生成中"淡绿标签 + 灰色进度条 | Timeline 执行中徽章灰化 ✓（进度条待加） |
| 可视化 | 图表/时间轴嵌入对话流 | 后续（非 #646 核心） |

## 三、任务列表（用户点名"简洁而优雅"）

| 项 | 参考做法 | MiQi 改法 |
|---|---|---|
| 分组 | 灰色小字分组标题（任务(2)/空间(1)）+ 展开收起 | 左侧栏已有分组（全部/进行中/待审阅/已完成）——样式微调 |
| 状态点 | **彩色小圆点**（青=运行中/绿=完成）——不占空间 | 左侧任务条目加状态点 |
| 信息密度 | 一行一任务、细分割线或纯留白 | 条目间距/分割线优化 |
| 活跃态 | 运行中任务闪烁/青色点 | 进行中任务加呼吸点 |

## 四、配色体系

- 主按钮：近黑 #1f1f1f（✅ 已改）
- 状态：运行青 / 完成绿 / 等待灰（克制，不花哨）
- 卡片：白或浅灰底 + 细边框（1px #eceef1）+ 弥散阴影（✅ 已改）
- 背景：极浅灰（#f5f5f5）或纯白

## 五、落地顺序（建议）

1. **任务列表**（左侧栏：状态点/分组/留白）——独立组件，小改
2. **AI 消息去对话框 + 页眉行**（小头像+名字+状态）——ChatConsole 渲染改
3. 卡片细节（步骤指示 1/4、进度条）——按演示需要
