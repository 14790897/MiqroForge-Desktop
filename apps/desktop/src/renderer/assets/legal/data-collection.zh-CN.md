# 个人信息收集清单

为了让用户（以下或称“您”）正常使用我们的产品、服务，我们会按照合法、正当、必要、诚信的原则收集用户的个人信息，在收集用户的个人信息后，我们会严格依照法律法规规定保护用户的个人信息安全。为了方便用户了解我们收集用户个人信息的情况，我们准备了本清单。

本清单是我们对主要业务场景所可能收集的个人信息的汇总说明，并不代表用户使用我们的产品或服务时，我们将收集、使用本清单中全部信息。仅当用户使用特定产品或服务，我们才会基于为实现向用户提供服务的目的，收集用户的相关个人信息。

| 业务场景 | 个人信息字段 | 收集/使用目的 |
| --- | --- | --- |
| 登录 | 手机号码、密码或验证码 | 为了实现登录功能 |
| Agent服务 | 您主动输入或上传的文本、图片、文件、录音文件、对话上下文、任务目标、工具调用参数、模型输出、执行状态及相关操作记录 | 为了理解和执行用户提出的任务，在用户授权范围内调用模型、文件工具、命令执行工具、Skills、MCP服务或插件，并向用户展示处理结果 |
| 保障网络访问和服务的基本安全以及便于使用产品 | IP地址、用户日志（用户登录日志、操作日志） | 为了保障网络访问、服务稳定性、异常排查、风险识别和安全防护 |
| 客户服务 | 您与我们的通信或通话记录、您提供的账号信息、您提供的联系方式信息、您为了证明相关事实提供的信息。前述信息为我们向您提供客户服务的必要信息 | 为了联系用户、定位并处理问题、记录处理方案及结果 |

个人信息的收集处理详情可参见《MiQroForge DeskTop隐私政策》。
